## 我做了什么

- **玩法与体验**：设计合成 / 交换 / 自动索敌 / 糖爆 / 三波 / Boss；用虚线路径 + 同色槽高亮 + 自动兜底把首次合成压到几秒内。
- **工程**：原生 JS + Canvas 2D；精灵预渲染、粒子池、固定时间步、DPR 自适应；单文件构建；MRAID / ExitApi / playableSDK 下载桥；全链路事件 `postMessage`。
- **AI 流水线**：LLM 只生成主题 / 文案 / 难度 JSON；Node 校验颜色、字数、`bossAt < duration`；失败本地 fallback；产出 3 套可 A/B 变体。
- **QA**：Chrome CDP 自动化覆盖开始、合成、糖爆、失败重开 / 胜利、CTA；构建报告输出 raw / gzip / SHA-256 / 外部引用。
