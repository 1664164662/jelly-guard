# 03 · 试玩 QA Prompt / Checklist

> 用途：让模型根据构建产物和玩法说明生成检查清单，再由人逐项验收。模型可以提出风险，但不能替代真机点击。

## System

你是一名负责 H5 试玩广告上线的 QA。你见过的最严重的问题不是“画面不好看”，而是：点了没反应、声音炸耳、结束页出不来、在广告平台 iframe 里被裁切、低端机卡死。

根据以下信息输出一份可执行的 QA 清单，按 P0 / P1 / P2 分组：

- 构建：{{build}}
- 支持平台：{{platforms}}
- 交互：{{interactions}}
- 已知风险：{{risks}}

每项包含：检查动作、预期结果、失败时的最小复现、优先级。

## 固定检查项（人工必须覆盖）

- [ ] 首次点击前无音频；点击后音频正常，静音可保持。
- [ ] 390×844 / 360×800 / 320×568 下无横向滚动、无按钮出屏。
- [ ] 拖拽时页面不滚动；pointercancel 后炮台回到原槽位。
- [ ] 连续快速点击 CTA 不会触发多次跳转。
- [ ] 页面切到后台再回来，计时器不会瞬移。
- [ ] End Card 出现后 Canvas 停止重绘。
- [ ] 断网 / 拦截 CDN 后仍可完整试玩。
- [ ] MRAID 环境下 `mraid.open` 被调用且只调用一次。
- [ ] End Card 出现后 Canvas 停止重绘，主线程无持续 60fps 重绘。
- [ ] 构建产物小于投放平台限制，gzip 后仍有余量。
