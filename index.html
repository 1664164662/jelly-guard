01 / WHY THIS LOOP

为什么是「合成 + 塔防」？

试玩广告的第一竞争对手不是别的游戏，是用户的拇指。这个组合把「看懂规则」和「获得反馈」都压到了一次拖拽里， 同时天然适合做 15–30 秒的高潮曲线。

01

3 秒能看懂

同色炮台、拖到一起、变强。没有文字教程也能靠高亮和一次自动引导完成第一次合成。

COGNITIVE LOAD
02

反馈密度高

每次合并都有音效、粒子、光环、数字跳变和屏幕轻震；30 秒内能完成 4 次明确的成长。

GAME FEEL
03

单手可完成

拖拽是唯一核心操作，糖爆是唯一主动技能。没有摇杆、没有多指操作，适合信息流场景。

ONE THUMB
04

可拆成变体

主题、文案、难度、Boss 时间点都能参数化。同一套引擎可以快速产出不同素材做 A/B。

SCALE

是把「想继续玩」压缩进几十秒。”

02 / 30-SECOND ARC

一条为“划走”设计的节奏线

每个时间段只回答一个问题：现在要做什么？做完会怎样？下一波还有什么？

  1. 00–03s

    先给情绪，再给规则

    果冻吉祥物 + 一句话卖点 + 大按钮。点击后 0 延迟进入战场，不插入加载页。

    START SCREEN
  2. 03–10s

    一次拖拽完成教学

    虚线路径 + 同色高亮 + 光标提示。若约 6 秒仍没有完成合成，系统会自动完成第一次，保证体验不断线。

    TUTORIAL + IDLE ASSIST
  3. 10–22s

    压力与补给交替

    第 2 波加速怪、第 3 波铁甲怪；三个时间点空投新炮台，让玩家在“继续合”与“补覆盖”之间做选择。

    WAVE 2–3 + SUPPLY
  4. 22–30s

    Boss 把情绪拉到顶

    Boss 入场震屏 + 血条 + 狂暴提示；攒满的「糖爆」成为玩家的高潮按钮，清场后进入结算。

    BOSS + SUGAR BURST
  5. END

    结果页只做一件事

    分数、合并数、击杀数建立成就感；应用卡 + 评分 + 免费下载按钮完成转化，同时保留“再玩一次”。

    END CARD + CTA

04 / AI, NOT DECORATION

AI 不是噱头，
是流水线上的一个工位。

这个项目里，LLM 不直接写游戏逻辑。它只做最擅长的部分：根据 brief 产出主题、文案和难度参数； 代码负责结构校验、边界约束、回退和构建。这样既能快速试错，又不会把不可控输出带进投放素材。

  1. 01
    BRIEF

    一句主题描述 + 目标人群 + 约束（时长、Boss 时间、文案长度）。

  2. 02
    LLM → JSON

    DeepSeek / OpenAI-compatible API，要求只返回符合 schema 的 JSON。

  3. 03
    VALIDATE / FALLBACK

    校验颜色、字数、数值区间；失败自动使用本地模板，不让构建中断。

  4. 04
    BUILD

    生成浏览器配置 → 单文件试玩 → 尺寸 / gzip / 外部请求断言。

✳

真实边界：这是个人求职 Demo，不是冰川网络官方项目，也没有真实投放数据。所有“效果”都是工程指标和可复现的交互，不编造 CTR / IPM。

BUG 01FIXED

全合成后，只剩一座炮台

最初炮台只打自己这一列，玩家把资源全部合成到 Lv.5 后，其他列直接失守。

修复同轨优先 + 跨轨兜底索敌；高等级炮台可以转火，但同轨仍优先。
BUG 02FIXED

结算后帧率掉到 20

End Card 的 backdrop-filter 叠在持续重绘的 Canvas 上，每次合成都要重新模糊整屏。

修复结算时停掉 Canvas 渲染并切换静态渐变背景，帧率恢复，视觉也更干净。
BUG 03FIXED

新手不知道拖哪里

第一版只有文字提示，首次合并平均发生在 12 秒之后，前半段几乎没有成长反馈。

修复路径虚线 + 同色槽高亮 + 约 6 秒仍无合成时自动完成第一次；主动操作可在 2–4 秒内完成首合。
